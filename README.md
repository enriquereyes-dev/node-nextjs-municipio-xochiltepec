# Xochiltepec Emblemático

Plataforma web turística y cultural para el municipio de Xochiltepec, Puebla.

## Objetivo

Mostrar y administrar información cultural, territorial y visual del municipio:

- Fotografías
- Categorías
- Localidades
- Colonias
- Barrios
- Juntas auxiliares
- Lugares emblemáticos
- Historia y cultura local

## Stack técnico

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Bcrypt
- Multer
- Cloudinary

### Frontend

- Next.js
- TypeScript
- React
- CSS/Tailwind opcional
